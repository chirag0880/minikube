 Install Using the Official Script (Recommended, Simplest)
The official script automatically downloads and installs the latest version of Helm, making it suitable for most users.

Download the installation script:

```bash

curl -fsSL -o get_helm.sh https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3

```

Grant execute permission:

```
./get_helm.sh
```
check vesrion 

```bash
helm version
```
